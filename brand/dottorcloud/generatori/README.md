# Generatori

Gli script che producono il materiale del marchio dai token: vedi "Rigenerare" nel
[README del marchio](../README.md). Le cartelle che leggono e scrivono sono in
`percorsi.py`; `oklch.py` tinge i grigi di Espresso verso il verde del marchio,
`contrasto.py` misura i contrasti che `genera_token.py` controlla.

`rendi_png.py` e `screenshot_sito.py` vogliono `pip install playwright pillow` e un
Chromium.
