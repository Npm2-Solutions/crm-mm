# Icons

Le icone Lucide (v1.49, licenza ISC) più usate in DottorCloud: tratto 2, angoli arrotondati, griglia 24×24. Nel codice si usano inline con `stroke="currentColor"` così prendono il colore del testo; questi file hanno il tratto fissato a `ink-900` (`#16201e`) per poterli vedere come immagini, quindi vanno bene solo su fondi chiari. Per il tema scuro o un altro colore usa l'icona inline dal pacchetto `lucide` o `lucide-static`.

Taglie: 16px (`icon-sm`) nei controlli e nelle righe, 18–20px (`icon-md`) nella barra laterale e nei titoli.
