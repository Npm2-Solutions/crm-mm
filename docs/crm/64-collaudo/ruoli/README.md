# 64 · Le liste dei ruoli

## A cosa serve

Una lista da spuntare per ogni ruolo del Poliambulatorio San Luca, nell'ordine di una
giornata di lavoro, per il livello 2 del collaudo ([README](../README.md)) e per il
centro pilota ([centro-pilota.md](../centro-pilota.md)), dove ogni ruolo del centro
la rifà sul suo sito. Ogni riga ha un codice, cosa fare, cosa deve succedere
(*Atteso*) e lo spazio per una nota; una riga che non va è una segnalazione con quel
codice ([segnalazioni.md](../segnalazioni.md)).

## Come si usano

1. Si stampano, o si aprono sul telefono: su GitHub le caselle si leggono come caselle.
2. Si fanno nell'ordine: molte righe aspettano quella di un altro ruolo (il
   preventivo del dentista, la firma del paziente, il «Manda da firmare» della
   segreteria), e lo dicono con il link.
3. Le righe segnate *(telefono)* si fanno sul telefono; il giorno 4 del calendario si
   rifà sul telefono almeno metà della lista.
4. Accanto a una casella non spuntata, sempre il codice della segnalazione.
5. A fine giornata le liste vanno al coordinatore del collaudo, che apre le
   segnalazioni ancora non aperte.
